# Twitter Sentiment Analysis

## About the Project
This project analyzes the sentiment of tweets using Python. It counts positive and negative words in each tweet to determine whether the text is positive or negative.

The project also keeps track of the number of retweets and replies for each tweet.

## Features
- Count positive words in tweets.
- Count negative words in tweets.
- Calculate the net sentiment score.
- Read tweet data from a CSV file.
- Save the results to a new CSV file.

## Technologies Used
- Python
- CSV files
- OS module

## Project Files
- `sentiment_analysis.py` — The main Python script.
- `project_twitter_data.csv` — The input file containing tweet data.
- `positive_words.txt` — A list of positive words.
- `negative_words.txt` — A list of negative words.
- `resulting_data.csv` — The output file generated by the program.

## How It Works
1. The program reads the tweet data from a CSV file.
2. It counts the positive and negative words in each tweet.
3. It calculates the net sentiment score.

   `Net Score = Positive Score - Negative Score`

4. It saves the results in `resulting_data.csv`.

## How to Run
1. Make sure Python is installed.
2. Place all required input files in the same folder as the Python script.
3. Run the following command:

   `python sentiment_analysis.py`

4. Open `resulting_data.csv` to view the results.

## Output
The output CSV file contains the following columns:
- Number of Retweets
- Number of Replies
- Positive Score
- Negative Score
- Net Score

## Purpose
This project demonstrates basic text analysis, file handling, and sentiment scoring using Python.
